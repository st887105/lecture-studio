# 車城國小｜簡報與你，同一個畫面Meet視訊分享

車城國小資訊老師製作

正式網站：https://st887105.github.io/lecture-studio/

## 三種講課方式

1. **直接操作網站**：貼入 https 教材網址，按「開啟互動網站講課」。原網站允許嵌入時，可以直接點連結、捲動與換頁，講師人物疊在同一分頁。Meet 請分享「車城國小｜互動網站講課」。若網站拒絕嵌入，瀏覽器安全限制無法由本工具解除，請改用方式 3。
2. **PDF／圖片**：匯入 PDF 或多張圖片，可在工作室、輸出頁直接點畫面左右半邊，或用方向鍵／按鈕換頁。PowerPoint 可先匯出 PDF。Meet 請分享「車城國小｜分享輸出」。
3. **原分頁／獨立 PowerPoint**：擷取原教材分頁，開啟「浮動監看」，再回教材操作。支援 Document Picture-in-Picture 的桌面 Chrome／Edge 可置頂監看；其他瀏覽器使用並排視窗。預設拒絕應用程式視窗；獨立 PowerPoint 視窗需勾選進階選項，不可選含有本站的 Chrome／Edge 視窗。

## 會說話的本人似顏繪

目前依使用者提供的兩張黑衣研習照片製作似顏繪；維持自然臉長，臉頰只輕微修飾，使用清楚輪廓與簡化色塊。角色檔為 teacher-gestures-v2.png（講師三姿勢）與 onion-gestures.png（洋蔥寶寶三姿勢），啟用「似顏繪說話」後，以攝影機 Face Landmarker 的 jawOpen 數值驅動原圖嘴唇張閉；未開鏡頭或失去追蹤時嘴巴閉合。不需要在網站填入生圖 API key，也不是每幀呼叫生圖服務。

按「測試嘴型與手勢（8 秒）」可在不開鏡頭時先看示範；示範並不代表實際追蹤。正式使用請開啟攝影機、等待「嘴型同步中」，聲音仍由 Meet 麥克風傳送。這是 2D 張閉嘴動畫，並非逐字音素級對嘴；人物相似程度與實際攝影機同步仍請在上課裝置確認。

模型已在本機瀏覽器成功載入，並對角色圖完成一次真實臉部與嘴型推論；同時已目視檢查示範嘴型及測試失去追蹤會閉嘴。原照片沒有上傳到儲存庫，網站只放生成的角色圖。

「真人」顯示即時攝影機；「似顏繪說話」顯示生成角色及攝影機驅動的嘴型。

## 浮動監看與全螢幕講課的差別

- 浮動監看：操作原網站或 PowerPoint 時，另外開啟置頂合成預覽；不是取代原教材的操作介面。需桌面瀏覽器支援置頂視窗，否則並排使用。
- 全螢幕講課／換頁：開啟分享輸出頁，可直接控制已匯入的 PDF／圖片換頁，再按全螢幕。擷取中的外部網站仍須回原網站操作；可以嵌入的網站則使用「互動網站講課」。

## 防鏡射與全螢幕

本站拒絕擷取整個螢幕，並在瀏覽器支援 Capture Handle 時識別及阻擋本站分頁。進階視窗擷取仍須人工選獨立應用程式，無法保證辨識所有瀏覽器不提供識別的來源。

輸出頁提供「全螢幕」與 F 快捷鍵，需使用者在該頁點擊；F11 也能隱藏瀏覽器工具列。完整構圖會依螢幕比例留邊；填滿裁切會裁掉部分教材。控制列會自動隱藏，互動網站頁可按右上角「設定」再顯示。

## 聲音測試

開啟本機收音測試後可看音量、試錄 3 秒再播放。只有按下試錄時才在本機錄音。這只能證明本機收音，不能證明 Meet 已送達。

實際講話請使用 Meet 麥克風，在 Meet 選同一支裝置。請用第二裝置加入會議、關閉第二裝置麥克風並戴耳機確認，或請學員確認，再勾選人工確認。本站不把麥克風另行送入輸出，避免重複收音；教材音訊尚未轉送。

## 部署與資料

純靜態網站，GitHub Pages 使用 main 分支 /(root)，包含 .nojekyll，不需後端或 API key。PDF.js、MediaPipe 模型與程式首次由 jsDelivr／Google Storage 載入，字型使用 Google Fonts。教材、鏡頭、錄音不由本程式上傳，Meet 分享則由 Meet 傳送。

## 驗證範圍

已通過程式檢查、防鏡射來源判斷、人物像素處理、換頁／暫停、網址驗證與音訊清理檢查。本機瀏覽器已實測兩頁 PDF 匯入與換頁，以及互動網站連結導航；也確認禁止嵌入的目的網站會被瀏覽器阻擋。攝影機實際相似程度、麥克風回放、置頂支援及 Meet 學員端收看／收音請在上課裝置再測一次。

## 2026-10-30 同頁講課

1. 在準備頁按「開始單頁講課」，會在目前分頁展開大型講課工作區，不開新視窗，也不必進入瀏覽器全螢幕。
2. 下方固定工具列可直接使用畫筆、橡皮擦、復原、清除與放大鏡。上方可換頁、暫停；Esc 取消目前工具。
3. 右上「教材／人物設定」可展開同頁側欄，切換「教材」與「人物」。匯入 PDF、切換角色會直接更新同一張畫面。
4. 按「返回準備」會把原本的畫布和設定搬回原位置；教材、角色、已畫筆跡及擷取串流不會因切換版面而重建。
5. Meet 一次選好「乾淨輸出」分頁後，講課時留在單頁工作區操作。工具列和設定側欄不會畫進輸出的 canvas；筆跡與放大效果會同步進入輸出。
6. 浮動監看改為「浮動工具箱（選用）」，支援的 Chrome／Edge 可在浮窗中直接使用畫筆、橡皮擦、放大鏡和復原，無需回主工作室選工具。浮窗中的 Esc 也可取消工具。原生置頂支援仍取決於瀏覽器。
7. 擷取原網站後可以在影像上畫記，但擷取影像不能代替原網頁按鈕。操作原站時可選用浮動工具箱；PDF／圖片則可在單頁工作區完整操作。

本次已實測 PDF 匯入／換頁／筆跡保存、同頁角色切換、返回準備後節點與狀態保留、乾淨輸出同步。原生置頂視窗與 Meet 學員端收看／收音仍請在上課瀏覽器確認。
